# Telegram Business AI Assistant Bot

Telegram-бот — персональный бизнес-помощник с AI. Подключается через Telegram Business, читает ваши чаты и отвечает в вашем стиле.

## Возможности

- **Telegram Business** — подключение через настройки Telegram
- **AI-ответы** — бот отвечает в стиле владельца через OpenAI-совместимый API
- **Системный промпт** — настраиваемый промпт для управления стилем ответов
- **Чтение чатов** — бот читает и сохраняет историю переписок
- **Авто-ответ** — автоматические ответы клиентам от вашего имени
- **Премиум-эмодзи** — кастомные эмодзи во всех сообщениях и кнопках

## Меню бота

| Раздел | Описание |
|--------|----------|
| ✍ Предложение | Системный промпт — определяет стиль AI |
| 🔒 API ключ | Ключ для OpenAI (или совместимого API) |
| 📊 История | Просмотр и очистка истории чатов |
| 👁 Чаты | Управление отслеживаемыми чатами |
| ⚙ Настройки | Модель AI, API URL, авто-ответ |

## Запуск

```bash
cd business-bot
pip install aiogram aiosqlite aiohttp
BOT_TOKEN=your-token python main.py
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `BOT_TOKEN` | Токен Telegram бота | — (обязательно) |
| `DATABASE_PATH` | Путь к SQLite базе | `data/bot.db` |
| `DEFAULT_API_URL` | URL OpenAI API | `https://api.openai.com/v1` |
| `DEFAULT_MODEL` | Модель AI | `gpt-4o-mini` |
